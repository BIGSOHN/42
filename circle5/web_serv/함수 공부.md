**gai_strerror**

## 네트워크 바이트 순서 변환

**htons, htonl, htohs, ntohl**
- ```htons() ``` : host to network short (16비트)
- ```htonl() ``` : host to network long (32비트)
- ```ntohs() ``` : network to host short
- ```ntohl() ``` : network to host long
- 빅 엔디안(네트워크 바인트 순서)과 호스트 바이트 순서 간 변환을 수행 합니다.

## I/O 멀티플렉싱

### **select**
- ```int select(int nfds, fd_set *readfds, fd_set *write fds, fd_set *exceptfds, struct timeval *timeout)```
- ```nfds``` : 검사할 파일 디스크립터의 최대값 + 1
- ```readfds``` : 읽기 가능 상태를 검사할 fd들의 집합(NULL 가능)
- ```writefds``` : 쓰기 가능 상태를 검사할 fd들의 집합(NULL 가능)
- ```exceptfds``` : 예외 상태를 검사할 fd들의 집합(NULL 가능)
- ```timeout``` : 대기 시간(NULL이면 무한 대기)
- 여러 파일 디스크립터를 동시에 모니터링하여 I/O 가능한 상태를 감지합니다.
- 최대 FD_SETSIZE(보통 1024)개의 파일 디스크립터만 처리 가능
- 매번 fd_set을 다시 설정해야 함
- 가장 이식성이 좋음

### **poll**
- ```int poll(struct pollfd *fds, nfds_t nfds, int timeout)```
- ```fds``` : pollfd 구조체 배열
- ```nfds``` : 배열의 크기
- ```timeout``` : 대기 시간(밀리초, -1이면 무한 대기, 0이면 즉시 반환)
- **pollfd 구조체**
``` c++
struct pollfd {
    int fd;         // 파일 디스크립터
    short events;   // 검사할 이벤트들
    short revents;  // 발생한 이벤트들 (출력)
};
```
- select보다 효율적인 I/O멀티플렉싱 방법
- 파일 디스크립터 개수 제한이 없음
- Linux와 대부분의 Unix 시스템에서 지원

### **epoll 계열(Linux 전용)**
- #### ```epoll_create()``` : epoll 인스턴스 생성
- ```int epoll_create(int size);```
- 대량의 연결을 효율적으로 처리할 수 있다.
- Edge-triggered와 Level-triggered 모드 지원
- 인자들
    - ```size``` : 힌트 값(현재는 무시됨, 0보다 큰 값)
    - ```flags``` : 플래그(epoll_cr)
- ```epoll_ctl()``` : 모니터링할 파일 디스크립터 추가 / 수정 / 삭제
- ```int epoll_ctl(int epfd, int op, int fd, struct epoll_event *event);```
- **epoll_event 구조체**
```c++
struct epoll_event {
    uint32_t events;    // 이벤트 마스크
    epoll_data_t data;  // 사용자 데이터
};

typedef union epoll_data {
    void *ptr;
    int fd;
    uint32_t u32;
    uint64_t u64;
} epoll_data_t;
```
- 인자들
    - ```epfd``` : epoll_create로 생성한 epoll 파일 디스크립터
    - ```op``` : 수행할 연산
        - ```EPOLL_CTL_ADD``` : fd 추가
        - ```EPOLL_CTL_MOD``` : fd의 이벤트 수정
        - ```EPOLL_CTL_DEL``` : fd 제거
    - ```fd```: 대상 파일 디스크립터
    - ```event``` : 이벤트 구조체(EPOLL_CTL_DEL 일때는 NULL 가능)
- 반환값
    - 성공시 : 0
    - 실패시 : -1 (errno 설정됨)
-  #### ```epoll_wait()``` : 이벤트 대기
- ```int epoll_wait(int epfd, struct epoll_event *events, int maxevents, int timeout);```
- 인자들
    - ```enfd``` : epoll 파일 디스크립터
    - ```events``` : 발생한 이벤트들을 저장할 배열
    - ```maxevents``` : events 배열의 최대 크기
    - ```timeout``` : 대기 시간 (밀리초, -1이면 무한 대기)
- 반환값
    - 성공시 : 발생한 이벤트의 개수
    - 타임아웃 : 0
    - 실패시 : -1(errno 설정됨)

**kqueuq 계열(BSD/macOS 전용)**
- ```kqueue()``` : 커널 이벤트 큐 생성
- ```kevent()``` : 이벤트 등록 및 대기
- BSD 계열에서 사용하는 고성능 이벤트 알림 메커니즘

## 소켓 통신
### **socket**
- ```int socket(int domain, int type, int protocol)```
- 소켓을 생성합니다. (예: TCP는 SOCK_STREAM, UDP는 SOCK_DGRAM)
- 인자들
    - ```domain``` (주소 패밀리) :
        - ```AF_INET``` : IPv4
        - ```AF_INET6``` : IPv6
        - ```AF_UNIX```/```AF_LOCAL``` : Unix 도메인 소켓
        - ```AF_UNSPEC``` : 지정하지 않음
    - ```type``` (소켓 타입) :
        - ```SOCK_STREAM``` : TCP (연결 지향, 신뢰성)
        - ```SOCK_DGRAM``` : UDP (비연결, 데이터그램)
        - ```SOCK_RAW``` : Raw 소켓 (낮은 수준 접근)
        - ```SOCK_SEQPACKET``` : 순서 보장 패킷 소켓
    - ```protocol``` : 프로토콜 번호 (보통 0으로 설정하면 자동 선택)
        - ```IPPROTO_TCP``` : TCP 명시
        - ```IPPROTO_UDP``` : UDP 명시
        - ```0``` : 자동 선택
- 반환값
    - 성공시 : 소켓 파일 디스크립터(0 이상)
    - 실패시 : -1(errno 설정됨)

### **bind**
- ```int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen)```
- 소켓을 특정 주소와 포트에 바인딩한다.
- 인자들
    - ```sockfd``` : socket()으로 생성한 소켓 파일 디스크립터
    - ```addr``` : 바인딩할 주소 구조체 포인터
    - ```addrlen``` : addr 구조체의 크기
- 주요 주소 구조체들
```c++
// IPv4
struct sockaddr_in {
    sa_family_t sin_family;     // AF_INET
    in_port_t sin_port;         // 포트 번호 (네트워크 바이트 순서)
    struct in_addr sin_addr;    // IP 주소
    char sin_zero[8];           // 패딩
};

// IPv6
struct sockaddr_in6 {
    sa_family_t sin6_family;    // AF_INET6
    in_port_t sin6_port;        // 포트 번호
    uint32_t sin6_flowinfo;     // Flow 정보
    struct in6_addr sin6_addr;  // IPv6 주소
    uint32_t sin6_scope_id;     // Scope ID
};

// Unix 도메인
struct sockaddr_un {
    sa_family_t sun_family;     // AF_UNIX
    char sun_path[108];         // 소켓 파일 경로
};
```
- 반환값
    - 성공시 : 0
    - 실패시 : -1(errno 설정됨)
### **listen**
- ```int listen(int sockfd, int backlog)```
- 서버 소켓을 연결 대기 상태로 만든다.
- 인자들
    - ```sockfd``` : 바인딩된 소켓 파일 디스크립터
    - ```backlog``` : 대기열의 최대 크기 (보통 5-128 사이)
        - 실제 구현에서는 시스템 설정에 의해 제한될 수 있음
        - ```SOMAXCONN``` 상수로 시스템 최대값 확인 가능
- 반환값
    - 성공시 : 0
    - 실패시 : -1(errno 설정됨)

### **accept**
- ```int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen)```
- 클라이언트 연결을 수락하고 새로운 소켓을 반환한다.
- 인자들
    - ```sockfd``` : listen 상태의 소켓 파일 디스크립터
    - ```addr``` : 클라이언트 주소 정보를 저장할 구조체 (NULL 가능)
    - ```addrlen``` : addr 구조체 크기의 포인터 (입출력 인자)
        - 입력 : addr 구조체의 최대 크기
        - 출력 : 실제 저장된 주소 구조체의 크기
- 반환값
    - 성공시 : 새로운 연결을 위한 소켓 파일 디스크립터
    - 실패시 : -1 (errno 설정됨)

**connect**
- ```int connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen)```
- 클라이언트에서 서버에 연결을 시도한다.
- 인자들
    - ```sockfd``` : socket()으로 생성한 소켓 파일 디스크립터
    - ```addr``` : 연결할 서버의 주소 구조체
    - ```addrlen``` : addr 구조체의 크기
- 반환값
    - 성공시 : 0
    - 실패시 : -1 (errno 설정됨)

### **send/recv**
- 소켓을 통해 데이터를 송수신합니다.
- ```ssize_t send(int sockfd, const void *buf, size_t len, int flags)```
- 인자들
    - ```sockfd``` : 연결된 소켓 파일 디스크립터
    - ```buf``` : 전송할 데이터의 포인터
    - ```len``` : 전송할 데이터의 크기(바이트)
    - ```flags``` : 전송 옵션
        - ```0``` : 기본 전송
        - ```MSG_DONTWAIT``` : 논블로킹 전송
        - ```MSG_NOSIGNAL``` : SIGPIPE 시그널 방지(LINUX)
        - ```MSG_OOB``` : Out-of-band 데이터 전송
        - ```MSG_MORE``` : 더 많은 데이터가 올 것임을 알림 (LINUX)
- 반환값
    - 성공시 : 실제로 전송된 바이트 수 (0이상, len보다 작을 수 있음)
    - 실패시 : -1 (errno 설정됨)
- ```ssize_t recv(int sockfd, void *buf, size_t len, int flags)```
- 인자들
    - ```sockfd``` : 연결된 소켓 파일 디스크립터
    - ```buf``` : 수신할 데이터를 저장할 버퍼
    - ```len``` : 버퍼의 크기(바이트)
    - ```flags``` : 수신 옵션
        - ```0``` : 기본 수신
        - ```MSG_DONTWAIT``` : 논블로킹 수신
        - ```MSG_OOB``` : Out-of-band 데이터 수신
        - ```MSG_PEEK``` : 데이터를 큐에서 제거하지 않고 확인만
        - ```MSG_WAITALL``` : 요청한 크기만큼 모든 데이터 수신까지 대기
- 반환값
    - 성공시 : 실제로 수신한 바이트 수 (0 이상)
    - 연결 종료 : 0 (정상적인 연결 종료)
    - 실패시 : -1 (errno 설정됨)

### 일반적인 소켓 사용 패턴
- 서버측
    1. socket() -> 소켓 생성
    2. bind() -> 주소 바인딩
    3. listen() -> 연결 대기 상태
    4. accept() -> 클라이언트 연결 수락
    5. recv()/send() -> 데이터 송수신
    6. close() -> 소켓 종료
- 클라이언트측
    1. ```socket()``` -> 소켓 생성
    2. ```connect()``` -> 서버 연결
    3. ```send()/recv()``` -> 데이터 송수신
    4. ```close()``` -> 소켓 종료

## 주소 정보 처리

### **getaddrinfo**

- ```int getaddrinfo(const char *node, const char *service, const struct addrinfo *hints, struct addrinfo **res)```
- 호스트명과 서비스명을 소켓 주소 구조체로 반환한다.
- 인자들
    - ```node``` : 호스트명 또는 IP 주소 문자열
    - ```service``` : 서비스명 또는 포트 번호 문자열
    - ```hints``` : 요청할 주소 정보의 조건을 지정하는 구조체 (NULL 가능)
    - ```res``` : 결과를 저장한 addrinfo 구조체 연결 리스트의 포인터
- addrinfo 구조체
```cpp
struct addrinfo {
    int ai_flags;           // 입력 플래그
    int ai_family;          // 주소 패밀리 (AF_INET, AF_INET6, AF_UNSPEC)
    int ai_socktype;        // 소켓 타입 (SOCK_STREAM, SOCK_DGRAM)
    int ai_protocol;        // 프로토콜 (IPPROTO_TCP, IPPROTO_UDP)
    socklen_t ai_addrlen;   // ai_addr의 크기
    struct sockaddr *ai_addr; // 실제 주소 구조체
    char *ai_canonname;     // 정규 호스트명
    struct addrinfo *ai_next; // 다음 addrinfo 구조체
};
```
- ai_flags 값들
    - AI_PASSIVE      // 서버용 소켓 (bind에 사용)
    - AI_CANONNAME    // 정규 호스트명 반환
    - AI_NUMERICHOST  // node를 숫자 주소로만 해석
    - AI_NUMERICSERV  // service를 숫자 포트로만 해석
    - AI_V4MAPPED     // IPv6에서 IPv4 매핑 주소 허용
    - AI_ALL          // 모든 주소 반환
    - AI_ADDRCONFIG   // 시스템에서 지원하는 주소 패밀리만 반환
- 반환값
    - 성공시 : 0
    - 실패시 : 0이 아닌 에러 코드

### **freeaddrinfo**
- ```void freeaddrinfo(struct addrinfo *res)```
- getaddrinfo로 할당된 메모리를 해제한다.
- 인자들
    - ```res``` : getaddrinfo로 할당된 addrinfo 구조체 연결리스트
- 특징
    - getaddrinfo가 동적으로 할당한 모든 메모리를 해제
    - 연결 리스트 전체를 해제하므로 첫 번째 노드만 전달하면 됨
    - 반환값 없음
    - NULL 포인터를 전달해도 안전함

## 소켓 옵션 및 정보

**setsockopt**
- ```int setsockopt(int sockfd, int level, int optname, const void *optval, socklen_t optlen)```
- 소켓 옵션을 설정합니다.
- 인자들
    - ```sockfd``` : 소켓 파일 디스크립터
    - ```level``` : 옵션이 적용될 레벨
    - ```optname``` : 설정할 옵션의 이름
    - ```optval``` : 옵션 값을 가리키는 포인터
    - ```optlen``` : optval이 가리키는 데이터의 크기
- 주요 level 값들
    - SOL_SOCKET      // 소켓 레벨 (일반적인 소켓 옵션)
    - IPPROTO_IP      // IP 레벨 (IPv4 옵션)
    - IPPROTO_IPV6    // IPv6 레벨 (IPv6 옵션)
    - IPPROTO_TCP     // TCP 레벨 (TCP 옵션)
    - IPPROTO_UDP     // UDP 레벨 (UDP 옵션)

**getsockname**
- ```int getsockname(int sockfd, struct sockaddr *addr, socklen_t *addrlen)```
- 소켓에 바인딩된 로컬 주소를 얻는다.
- 인자들
    - ```sockfd``` : 소켓 파일 디스크립터
    - ```addr``` : 로컬 주소를 저장할 구조체
    - ```addrlen``` : 입출력 인자 (입력: 구조체 크기, 출력 : 실제 주소 크기)
- 특징
    - 소켓에 바인딩된 로컬 주소와 포트 정보 조쇠
    - 동적 포트 할당 시 실제 할당된 포트 번호 확인에 유용
    - bind()후나 connect()후에 사용
- 반환값
    - 성공시 : 0
    - 실패시 : -1 (errno 설정됨)

**getprotobyname**
- ```struct protoent *getprotobyname(cont char *name)```
- 프로토콜 이름으로 프로토콜 정보를 조회합니다.
- protoent 구조체
```cpp
struct protoent {
    char *p_name;       // 공식 프로토콜 이름
    char **p_aliases;   // 별명 목록
    int p_proto;        // 프로토콜 번호
};
```
- 인자들
    - ```name``` : 프로토콜 이름("tcp", "udp", "icmp" 등)
- 반환값
    - 성공시 : protoent 구조체 포인터
    - 실패시 : NULL
- 특징
    - /etc/protocols 파일에서 정보를 읽어옴
    - 정적 메모리에 저장되므로 free하면 안 됨
    - 스레드 안전하지 않을 수 있음

## 파일 및 시스템

**fcntl**
- ```int fcntl(int fd, int cmd, ...)```
- 파일 디스크립터의 속성을 조작합니다. (논블로킹 설정 등)
- 인자들
    - ```fd``` : 파일 디스크립터
    - ```cmd``` : 수행할 명령
    - ```...``` : cmd에 따른 추가 인자 (가변 인자)
- 주요 cmd 값들
    - F_GETFL / F_SETFL (파일 상태 플래그)
    - F_GETFD / F_SETFD (파일 디스크립터 플래그)
    - F_DUPFD (파일 디스크립터 복제)
    - F_SETLK / F_SETLKW / F_GETLK (파일 잠금)
- 주요 파일 상태 플래그들
    - O_APPEND    // 항상 파일 끝에 추가
    - O_ASYNC     // 비동기 I/O 시그널 활성화
    - O_DIRECT    // 직접 I/O (버퍼 캐시 우회)
    - O_NONBLOCK  // 논블로킹 모드
    - O_SYNC      // 동기 쓰기
- 반환값
    - 성공시 : cmd에 따라 다름 (F_GETFL, F_GETFD는 플래그 값, F_DUPFD는 새 fd)
    - 실패시 : -1 (errno 설정됨)

**read**
- ```ssize_t read(int fd, void *bufm size_t count)```
- 파일이나 소켓에서 데이터를 읽습니다.
- 요청한 바이트 수보다 적게 읽을 수 있음
- 논블로킹 모드에서는 데이터가 없으면 즉시 반환
- 시그널에 의해 중단될 수 있음

**socketpair**
- ```int socketpair(int domain, int type, int protocol, int sv[2])```
- 연결된 소켓 쌍을 생성합니다.
- 인자들
    - ```domain``` : 주소 패밀리 (보통 AF_UNIX)
    - ```type``` : 소켓 타입 (SOCK_STREAM, SOCK_DGRAM 등)
    - ```protocol``` : 프로토콜 (보통 0)
    - ```sv``` : 생성된 소켓 쌍을 저장할 배열
- 반환값
    - 성공시 : 0 (sv[0], sv[1]에 연결된 소켓 쌍 생성)
    - 실패시 : -1 (errno 설정됨)
- 특징
    - 양방향 통신이 가능한 연결된 소켓 쌍을 생성
    - 주로 부모-자식 프로세스 간 IPC에 주로 사용
    - pipe()보다 유연함 (양방향, select/poll 사용 가능)
    - Unix 도메인에서만 사용 가능

## 프로세스 관리
**kill**
- ```int kill(pid_t pid, int sig)```
- 프로세스에 시그널을 보냅니다.
- 인자들
    - ```pid``` : 대상 프로세스 ID 또는 프로세스 그룹
    - ```sig``` : 전송할 시그널 번호
- pid 값의 의미
    - pid > 0 : 특정 프로세스 ID로 시그널 전송
    - pid == 0 : 현재 프로세스와 같은 프로세스 그룹의 모든 프로세스에 시그널 전송
    - pid == -1 : 권한이 있는 모든 프로세스에 시그널 전송 (자기 자신 제외)
    - pid < -1 : 프로세스 그룹 ID가 pid인 그룹의 모든 프로세스에 시그널 전송

**signal**
- ```sighandlet_t signam(int signum, sighandlet_t handler)```
- 시그널 핸들러를 등록합니다.
- 인자들
    - ```signum``` : 처리할 시그널 번호
    - ```handler``` : 시그널 핸들러 함수 포인터 또는 특수 값

## 파일 시스템
**access**
- ```int access(const char *pathname, int mode)```
- 파일의 접근 권한을 확인합니다.

**stat**
- ```int stat(const char *pathname, struct stat *statbuf)```
- 파일의 상태 정보를 얻습니다.
- stat 구조체
```cpp
struct stat {
    dev_t st_dev;         // 장치 ID
    ino_t st_ino;         // inode 번호
    mode_t st_mode;       // 파일 타입과 권한
    nlink_t st_nlink;     // 하드링크 개수
    uid_t st_uid;         // 소유자 사용자 ID
    gid_t st_gid;         // 소유자 그룹 ID
    dev_t st_rdev;        // 특수 파일의 장치 ID
    off_t st_size;        // 파일 크기 (바이트)
    blksize_t st_blksize; // I/O 블록 크기
    blkcnt_t st_blocks;   // 할당된 블록 수
    time_t st_atime;      // 마지막 접근 시간
    time_t st_mtime;      // 마지막 수정 시간
    time_t st_ctime;      // 마지막 상태 변경 시간
};
```
