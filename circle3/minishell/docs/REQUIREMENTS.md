# Minishell 과제 요구사항

42서울 Minishell 프로젝트의 공식 요구사항입니다.

---

## 1. 기본 기능

### 프롬프트 표시
- 새 명령을 기다릴 때 프롬프트를 표시합니다.

### 히스토리
- 작업 이력이 있어야 합니다.

### 실행 파일 검색 및 실행
- 올바른 실행 파일을 검색하고 실행합니다.
- PATH 변수를 기반으로 하거나 상대 또는 절대 경로를 사용

### 전역 변수 제한
- 수신된 신호를 나타내기 위해 **둘 이상의 전역 변수를 사용하지 마십시오.**
- 이 접근 방식은 신호 처리기가 기본 데이터 구조에 액세스하지 않도록 보장합니다.

---

## 2. 따옴표 및 특수 문자 처리

### 제외할 특수 문자
닫히지 않은 따옴표나 필요하지 않은 특수 문자를 해석하지 마십시오:
- `\` (백슬래시)
- `;` (세미콜론)

### 작은따옴표 (')
- 셸이 인용된 순서의 메타 문자를 해석하지 못하도록 처리

### 큰따옴표 (")
- 셸이 인용된 문자열 내의 메타 문자를 해석하지 않도록 처리
- **단, `$` (달러 기호)는 예외**

**주요 포인트**:
1. 큰따옴표(`"`)는 문자열을 감싸는 데 사용됩니다.
2. 큰따옴표 안에 있는 대부분의 특수 문자나 메타 문자는 일반 텍스트로 취급됩니다.
3. 하지만 `$` 기호는 예외적으로 여전히 변수 확장 등의 기능을 수행합니다.

---

## 3. 리다이렉션 구현

### `<` (입력 리다이렉션)
- 입력을 리다이렉션해야 합니다.

### `>` (출력 리다이렉션)
- 출력을 리다이렉션해야 합니다.

### `<<` (Here Document)
- 구분 기호가 제공되어야 하며, 구분 기호가 포함된 줄이 나타날 때까지 입력을 읽어야 합니다.
- **기록을 업데이트할 필요는 없습니다.**

### `>>` (추가 모드 출력 리다이렉션)
- 추가 모드에서 출력을 리다이렉션해야 합니다.

---

## 4. 파이프 구현

### `|` (파이프)
- 파이프라인의 각 명령 출력은 파이프를 통해 다음 명령의 입력에 연결됩니다.

---

## 5. 환경 변수 처리

### 환경 변수 확장
- 해당 값으로 확장되어야 하는 환경 변수 (`$` 뒤에 일련의 문자가 옴)를 처리합니다.

### `$?` 처리
- 가장 최근에 실행된 포어그라운드 파이프라인의 종료 상태로 확장되어야 합니다.

---

## 6. 시그널 처리

bash에서처럼 작동해야 하는 시그널들:
- `Ctrl-C`
- `Ctrl-D`
- `Ctrl-\`

### 대화형 모드에서

**Ctrl-C**
- 새 줄에 새 프롬프트를 표시합니다.

**Ctrl-D**
- 쉘을 나갑니다.

**Ctrl-\**
- 아무것도 하지 않습니다.

---

## 7. 내장 명령어 (Builtins)

쉘은 다음 내장 기능을 구현해야 합니다:

- `echo` (옵션 `-n` 포함)
- `cd` (상대 또는 절대 경로만)
- `pwd` (옵션 없음)
- `export` (옵션 없음)
- `unset` (옵션 없음)
- `env` (옵션이나 인자 없음)
- `exit` (옵션 없음)

---

## 8. 메모리 관리

`readline()` 함수는 메모리 누수를 일으킬 수 있습니다. 이를 고칠 필요는 없습니다.

**하지만** 이것이 여러분의 코드, 즉 여러분이 작성한 코드에 메모리 누수가 있을 수 있다는 의미는 아닙니다.
