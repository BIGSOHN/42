## Shell이란?

**Shell은 인터프리터입니다.**

- 쉘은 사용자의 목적인 응용 프로그램의 실행을 편하게 하기 위한 적절한 실행 환경을 제공하는 프로그램입니다.
- 운영체제의 핵심인 커널에 서비스를 요청하는 일종의 클라이언트입니다.
- shell은 shellscript라는 프로그래밍 언어를 실행시키는 인터프리터입니다.
- **인터프리터**: 코드를 문자열 형태로 입력받아 해당 코드를 실행하는 프로그램

---

## 인터프리터 동작 과정

### 1. Input (입력)
실행하고자 하는 코드를 문자열의 형태로 읽어들입니다.

### 2. Lexing (렉싱)
입력받은 코드를 특정 문자(연산자, 키워드 등)를 기준으로 분리하여 의미를 갖는 최소 단위로 구분하는 작업입니다.

### 3. Parsing (파싱)
코드를 해석하는 작업입니다.
- 렉싱 결과 획득한 token을 문법에 맞게 결합하여 의미를 갖는 구조로 재구성하는 과정
- 토큰들의 결합은 tree가 되는데 주로 이진 트리가 선택됩니다.

### 4. Evaluating (실행)
생성된 구문 트리를 순회하면서 해당 트리가 표현하는 문법 구조에 따른 동작을 수행합니다.

---

## 파싱 알고리즘

### 1. 재귀 하향식 파싱 알고리즘
- 우선순위가 높은 상위의 문법에서 시작하여 하위의 문법으로 구문 전체가 해석될 때까지 모든 문법을 적용해보는 알고리즘
- 해당 해석 함수로 해당 토큰에 대한 해석에 성공하면 이후 다음 토큰에 대해서 재귀적으로 함수 호출
- 해당 해석 함수로 해당 토큰에 대한 해석이 실패한다면 다음 하위 문법의 해석 함수를 호출

### 2. 플로이드의 파싱 알고리즘 (상향식 연산자 우선순위 파서)
- 우선순위의 존재가 핵심
- 재귀 하향식 파서가 문법에 해당하는 함수를 호출하여 해당 토큰을 파싱했다면, 연산자 우선순위 파서에서는 토큰의 타입에 맞는 파싱 함수를 호출합니다.
- 처음부터 올바른 방식으로 토큰을 결합하고 불가능하면 즉시 에러를 찾는 것

### 3. 프랫의 파싱 알고리즘 (하향식 연산자 우선순위 파서)
- 바인딩 파워의 형태로 나타남
- 바인딩 파워는 연산자가 인접한 노드를 끌어당겨 결합하려고 하는 힘을 의미합니다.
- 일반적으로 left binding power와 right binding power가 있습니다.
- 일반적으로 좌측 연산자의 rbp와 우측 연산자의 lbp가 경쟁합니다.
- 한 표현식의 rbp가 크다는 것은 해당 표현식의 오른쪽에 노드를 결합하려고 하는 힘이 강하다는 뜻
- lbp가 크다는 것은 노드가 다음 표현식의 왼쪽 자식으로 결합됨을 의미합니다.

## 토큰화 순서

**0. 이 과정 전체에서 열린 따옴표 체크를 해야 합니다.**

1. 특수 연산자 등 분리
2. 환경 변수 확장 수행
3. 명령과 인수 분할 (띄어쓰기 기준)

---

## 토큰을 위해 신경 써야 할 연산자

- `<`, `<<`, `>`, `>>`
- `|`, `||`, `&&`
- `(`, `)`
- 피연산자인 파일명과 커맨드 (커맨드 + 인자)

---

## 연산자 우선순위

번호가 작을수록 우선순위가 낮고 bp도 낮습니다.

1. 시작 노드 (초기값)
2. 논리 연산 (`&&`, `||`)
3. 파이프 (`|`)
4. 리디렉션 (`<`, `<<`, `>`, `>>`)
5. 서브쉘 (`(`)

**서브쉘, 즉 소괄호의 존재**는 파싱 과정에서 연산자의 우선순위를 조정하는 역할을 합니다.
- 상대적으로 괄호 내부의 연산자는 그 우선순위가 증가
- 그 반대로 괄호 바깥의 연산자는 그 우선순위가 감소

## 표준 입력 제어

### Canonical Input Mode (표준 입력 모드)
우리가 프로그램에서 흔히 사용하는 모델입니다.
- 입력이 들어오면 개행 혹은 EOF와 같은 종료 문자가 나올 때까지 처리를 기다리고 있다가 한 번에 문장 한 줄을 처리합니다.

### Noncanonical Input Mode (비표준 입력 모드)
- 문자가 행으로 그룹화되지 않으며, ERASE 및 KILL 처리가 수행되지 않습니다.
- 문자를 읽자마자 바로 처리하는 방식으로 동작합니다.

### 왜 Noncanonical Input Mode가 필요한가?

터미널의 표준 입력 모드에서는 `Ctrl+D`와 같은 특수 기호가 들어왔을 때 개행이 들어올 때까지 기다리기 때문에 우리가 그 입력이 들어오는 순간에 행동을 특정지을 수가 없습니다.

즉, `Ctrl+D`가 들어오자마자:
- 무시하거나 (문장의 중간에서 `Ctrl+D`가 들어왔을 때)
- EOF를 넣어주고 싶다면 (문장의 처음에 `Ctrl+D`가 들어왔을 때)

**Noncanonical input mode**를 활용해야 합니다.

## termios 구조체

C에서 noncanonical input mode를 사용하려면 프로그램에서 터미널 속성을 가져올 수 있어야 합니다. 우리는 `termios` 구조체를 활용해서 터미널의 데이터를 얻어오거나 적용할 수 있습니다.

```c
#include <termios.h>

// termios 구조체가 가지고 있는 property
struct termios
{
    tcflag_t c_iflag;    /* input flags */
    tcflag_t c_oflag;    /* output flags */
    tcflag_t c_cflag;    /* control flags */
    tcflag_t c_lflag;    /* local flags */
    cc_t     c_cc[NCCS]; /* control chars */
    speed_t  c_ispeed;   /* input speed */
    speed_t  c_ospeed;   /* output speed */
};
```

termios 구조체는 터미널의 거의 모든 속성을 다룰 수 있는 변수들로 이루어져 있습니다.
- input과 관련된 속성을 변경할 수 있는 `c_iflag`부터 출력 속도를 조절하는 `c_ospeed`까지

표준 입력으로 들어오는 특수 문자 처리를 위해 **c_lflag**를 집중적으로 봅니다.

---

### tcsetattr 함수

```c
int tcsetattr(int fildes, int optional_actions, struct termios *termios_p);
```

#### 기능
터미널 파일에 대한 속성을 설정합니다.

#### 매개변수
- **fd**: 터미널 file descriptor
- **optional_actions**: 동작 선택
  - `TCSANOW`: 속성을 바로 변경
  - `TCSADRAIN`: 송신을 완료한 후 변경
  - `TCSAFLUSH`: 송수신 완료 후 변경
- **termios_p**: 터미널 속성을 저장할 포인터

---

### tcgetattr 함수

```c
int tcgetattr(int fd, struct termios *termios_p);
```

#### 기능
터미널 파일에 대한 속성을 얻어서 `termios_p`에 저장합니다.

#### 매개변수
- **fd**: 터미널의 file descriptor
- **termios_p**: 터미널 속성을 저장할 포인터

## c_lflag의 속성

### ISIG
- signal을 받아들입니다.
- 이 플래그가 on이면 INTR, QUIT, SUSP, DSUSP와 같은 특수 문자를 받아들입니다.

### ICANON
- 이 플래그가 on이면 정규 모드로 입력이 이루어집니다.

### NOFLSH
- queue flush를 비활성화시킵니다.

### ECHO
- 반향을 설정합니다.
- 이 플래그가 off되어 있으면 입력은 반향되지 않습니다.

### ECHOE
- erase 문자를 반향합니다.
- ECHO 플래그가 on되어 있는 경우에, 스크린의 마지막 문자를 지웁니다.

### ECHOPRT
- ECHO, ECHOPRT가 on인 상태에서 ERASE가 발생하면 삭제되는 문자가 `\` 뒤에 표시됩니다.
- 만약 모든 문자를 삭제했다면 `/`가 출력됩니다.

### ECHONL
- NL 문자가 반향됩니다.
- ECHO 플래그와 상관없이 NL 문자를 반향합니다.

### ECHOCTL
- 제어 문자가 반향되도록 합니다.
- 이 플래그를 on 시킨 상태에서 `Ctrl+X`를 누르면 `^X`로 화면에 표시됩니다.

---

### Noncanonical Input Mode 설정

우리는 noncanonical input mode를 사용할 것이기 때문에 **ICANON을 off** 해주면 됩니다.

이때 입력하는 문자를 터미널에 반향(echo) 해주는 옵션도 off로 지정하고, 문자가 들어오고 내가 해당 문자를 판단한 후 동작하도록 설정합니다.
